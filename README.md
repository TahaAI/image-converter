# Image Converter

A sleek and easy-to-use desktop application built with **CustomTkinter** for converting images from **PNG** or **JPG** formats to **WEBP**. This lightweight app allows users to upload images, convert them with a single click, and save them effortlessly.

---

## Key Features

- Supports **PNG** and **JPG** input formats
- Converts images to **high-quality WEBP** format
- **Convert** button performs silent conversion without opening additional dialogs
- **Save** button opens a file dialog to store the converted image
- **Status messages** guide users step-by-step: upload, conversion, and save
- Modern and responsive GUI with **dark mode theme**
- Lightweight and standalone – can be converted to **EXE** for Windows

---

## Usage

1. **Upload** an image (PNG or JPG)
2. Click **Convert** to convert the image to WEBP
3. Click **Save** to store the converted image at your desired location
4. Follow **status messages** for guidance
